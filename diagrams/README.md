# Editable diagrams

Keep draw.io source files here and commit them alongside the website changes.
Jekyll excludes this folder from the generated website.

1. Open https://app.diagrams.net/ and choose Device storage.
2. Open research/template.drawio using File > Open From > Device.
3. Save a copy with a descriptive name, such as add-on.drawio.
4. Export as SVG into assets/img/research/ and save the editable .drawio here.
5. Set image and image_alt in the corresponding _research entry.

The template is a blank 1200 by 600 canvas. Adjust its dimensions to suit the diagram.
